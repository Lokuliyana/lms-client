# System Architecture & Technical Specifications

## 1. Tech Stack
- **Framework**: React 18+ (Vite) + TypeScript (Strict Mode).
- **Styling & UI**: Tailwind CSS + shadcn/ui + Lucide Icons.
- **State Management & Data Layer**: React Context (Global session/edit mode) + Custom Hooks Layer (with in-memory cache/revalidation pattern).
- **Form Handling & Validation**: React Hook Form + Zod.
- **Image Cropping**: `react-easy-crop`.
- **Target Backend Contract**: NestJS + PostgreSQL + Redis (Simulated via typed interfaces & mock storage adapters during dev).
